# Read Aloud

Luyện đoạn tiếng Anh để **nói chuyện**, không chỉ đọc thuộc: nghe → đọc thành tiếng → nhớ → kể lại.

Dùng **Google Chrome** và cho phép micro.

- Local: [http://127.0.0.1:5173](http://127.0.0.1:5173)
- GitHub Pages: [https://lelanit05.github.io/ReadAloud/](https://lelanit05.github.io/ReadAloud/)

```bash
python3 server.py
```

Bật Pages: repo **Settings → Pages → Deploy from a branch → `main` / root**.

## Bốn bước

1. **Nghe** — nghe cả đoạn, mắt đi theo chữ.
2. **Đọc** — đọc từng câu; app tô từ sai / thiếu.
3. **Nhớ** — chỉ còn chữ cái đầu; nói từ trí nhớ. Kẹt thì lộ chữ 2 giây.
4. **Kể** — kể lại như đang nói với bạn. Không cần giống từng chữ; app kiểm tra ý chính.

Có thể dán đoạn của bạn. Không dùng preview trong Cursor cho micro.
